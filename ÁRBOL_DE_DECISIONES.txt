🚨 PROBLEMAS COMUNES Y SOLUCIONES
════════════════════════════════════════════════════════════════════════════════

Problema: "psql: command not found"
Solución: 
  ├─ Instala PostgreSQL: brew install postgresql
  ├─ O agrega a PATH: export PATH="/usr/local/pgsql/bin:$PATH"
  └─ Verifica: psql --version


Problema: "psql: error: could not translate host name"
Solución:
  ├─ Verifica IP: ping 35.225.15.165
  ├─ Verifica credenciales en SQL
  └─ Usa VPN si es necesario


Problema: "syntax error in SQL at ..."
Solución:
  ├─ Ve a: GUIA_UPDATE_VIDEOS_IMAGES.md#Troubleshooting
  ├─ Verifica formato de strings (comillas)
  └─ Re-ejecuta sin cambios


Problema: "Queries lentas"
Solución:
  ├─ Es normal, esperar 3-5 segundos
  ├─ Verifica con: EXPLAIN ANALYZE (query)
  └─ Más info: GUIA_UPDATE_VIDEOS_IMAGES.md#Performance


Problema: "No data assigned"
Solución:
  ├─ Verifica: SELECT COUNT(*) FROM media_library;
  ├─ Si = 0: Ejecuta test_data_complete_enhanced.sql primero
  └─ Luego re-ejecuta UPDATE_VIDEOS_IMAGES.sql
