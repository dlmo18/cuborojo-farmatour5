⚠️ TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════════

"error: column doesn't exist"
  → Ejecutar schema.sql primero

"error: media_library is empty"
  → Ejecutar test_data_complete_enhanced.sql primero

"error: FK violation"
  → Verificar que media_library tiene datos

"No hay imágenes asignadas"
  → Verificar UPDATE_VIDEOS_IMAGES.sql se ejecutó
  → Ver logs con: SELECT * FROM missions WHERE image_id IS NULL;

"Videos no se reproducen"
  → Verificar URL en final_level_questions
  → Probar URL en navegador: https://vimeo.com/197211423

¿Lento?
  → Normal, esperar 3-5 segundos por tabla grande
  → Ver GUIA_UPDATE_VIDEOS_IMAGES.md#Troubleshooting
